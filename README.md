# 🧮 Calculator App

A simple, responsive calculator app built with HTML and CSS, with all logic handled directly through inline JavaScript event handlers inside the HTML elements.

### 🔗 Live Demo
https://calculator-app-6mla.onrender.com

### ✨ Features
- ➕ Performs basic arithmetic: Addition, Subtraction, Multiplication, Division
- 🧹 Functional AC and DEL buttons
- ⚡ Instant calculations without page reload
- 📱 Fully responsive on all screen sizes
- 🎨 Clean and modern button layout

### 🛠️ Built With
- HTML5 (with inline JavaScript logic)
- CSS3

### 💡 How It Works
This calculator doesn't use a separate JavaScript file or even a <script> tag. All functionality is built using inline `onclick` attributes directly on the buttons that update the display and evaluate expressions.

Example: `<button onclick="display.value += '7'">7</button>`
